# Enough to navigate the terminal

The NDG Linux Essentials course takes you through the fundamental skills you need to start working with the GNU/Linux operating system and its many, many distros. The course teaches you the prominence, history and the purpose behind Free & Open Source Software before guiding you through navigating the Linux terminal & a handful of the tools one uses in day-to-day life.

The course is structured in 18 modules and progressively gets harder or more complex in nature whilst still keeping everything relevant to daily operations. There are a number of labs, but these aren't graded nor are they open ended - you mearly follow a number of commands whilst reading the expected outcomes.

There are a number of exams that are MCQ based & have unlimited retries - not bad for some of the more complex stuff.

I finished this course in about 6 hours, rather than the advertised 70 & got a badge to add to linked in. I think it was a good use of my time and it has motivated me to continue learning more about Linux (and use it in projects like tbyte).
